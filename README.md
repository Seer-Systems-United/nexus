# Nexus
Polling sources retrieval library and polling analysis library.

## Overview
I plan to for this library to be a libary to pull polling data form public sources and centralize it so it can be analyzed. Currently the library is in its early stages and only supports YouGov USA, but I plan to add more sources in the future. The library will also have a polling analysis component that will allow users to analyze the polling data and build models.
